# finance-vs-buy

A super simple piece of slop to show the tradeoffs of financing a vehicle vs paying cash for it. Basically a nicer visual mechanism than the CLI python scripts I had lying around.
- Set your purchasing values
- Your estimated financing costs
- And your estimated returns on the cash/assets
- See some break even point as to where it makes sense to finance vs where it makes sense to buy given the time value of money

Note some super basic assumptions about inflation, rates of returns and access to markets means we shouldn't treat this as dead certain financial tool
